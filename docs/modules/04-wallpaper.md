# 模块 4：壁纸（Wallpaper）

## 0. 已落地范围（与下文规划的 Pexels 在线模块分开）

当前只落地了「**素材库图片 → 设为桌面壁纸**」这一段（`src/main/ipc/wallpaper.ts` +
`src/main/utils/wallpaperFit.ts`，见 Decision-016）：按目标屏物理像素判定并出派生 JPEG，
策略 `original`/`cover`/`blurred` 三档 + `auto` 入口，入口在预览面板、卡片右键菜单、检查器三处共用
`views/photos/composables/useWallpaper.ts`。下文 Browse/Rotation/Pexels 尚未实现。

| 分级 | 已落地 |
| --- | --- |
| 核心 | 单张设为壁纸（含按屏适配）；非素材、非 image 素材一律拒绝（与 image://rawfile:// 同一归属口径）；`mode` 过运行时白名单 + 缓存路径目录内断言；派生图缓存 `activeSubdir('wallpaper')/<id>/{W}x{H}-{策略}.jpg`（legacy 库落 `<userData>/wallpaper/`）+ 源变更失效 + LRU 24 |
| 判定 | 选档看 cover 丢弃面积与透明像素占比两条；目标尺寸按 `size × scaleFactor`（Retina 出物理像素）、长边封顶 4096；放大倍率只进 `reasons` 供文案，不参与选档 |
| 未做 | 深浅色联动、按应用切换、AI 生成壁纸（含下文全部规划项） |

## 2. 功能清单

| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 核心 (1.0)  | Browse（Pexels 12 分类）；Search；Favorites（收藏 + 同步到本地库）；Local Library（用户自添加）；Rotation（自动轮换 顺序/随机 + 多显示器）；Settings（保存路径 / Pexels API Key / 轮换间隔 / 多显示器规则） |
