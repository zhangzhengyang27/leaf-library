## 2. 功能清单

| 分级        | 功能                                                                                                                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 核心 (1.0)  | 唤起截图（全局快捷键 + 点击按钮）；框选；8 种标注（矩形/椭圆/箭头/画笔/马赛克/文字/撤销/重做）；保存到剪贴板 + 保存到文件；History（带 OCR 文字筛选 + 缩略图）；Settings（默认格式 png/jpg；保存路径；快捷键修改） |
| 增强 (1.0+) | OCR（真实实现，建议用 Tesseract.js / PaddleOCR 包装）；长截图（拼接）；延迟截图（3s）；马赛克 OCR 保护                                                                                                             |
| 探索 (2.0)  | AI 截图规则（"截所有错误信息框"）                                                                                                                                                                                  |

## 3. 状态机

```
[关闭] ─⌘⇧A─→ [Select Area 截图]
                    │
                    └─→ [Canvas Editor]
                            │
                            ├─→ 添加标注 ─→ [Undo/Redo stack]
                            ├─→ 保存到剪贴板 ─→ [Toast]
                            ├─→ 保存到文件 ─→ [历史+Toast]
                            ├─→ OCR ─→ [文本弹窗 + 复制]
                            └─→ 丢弃 → 回到关闭

后台：
[History 定时清理：30 天前的自动归档]
```

## 4. 与全局的联动

| 联动       | 实现                                  |
| ---------- | ------------------------------------- |
| Hub        | 最近 3 张截图缩略图 + "查看历史" 链接 |
| 命令面板   | `> 截图`、`> 截图历史`                |
| 全局快捷键 | `⌘⇧A` 全局截图；`⌘2` 跳到模块         |
| 系统托盘   | "截图" 单项菜单                       |
| 设置中心   | "截图" 分组                           |
| 数据层     | History 走 SQLite                     |
